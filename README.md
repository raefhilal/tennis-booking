# نظام حجز ملاعب التنس

تطبيق عربي متجاوب لحجز ملاعب التنس وإدارة الحجوزات والقواعد. يتكون المشروع من واجهة React/Vite وخادم Node.js/Express.

## المتطلبات

- Node.js 18 أو أحدث
- npm

## التشغيل محلياً

افتح نافذتي طرفية من مجلد المشروع:

**الواجهة (النافذة الأولى):**

```bash
cd client
npm ci
npm run dev
```

**الخادم (النافذة الثانية):**

```bash
cd server
npm ci
npm start
```

افتح رابط Vite الذي يظهر في النافذة الأولى. أثناء التطوير، يمرّر Vite طلبات `/api` إلى الخادم المحلي على المنفذ `3000`.

## تجهيز نسخة الإنتاج

```bash
cd client
npm ci
npm run build
cd ../server
npm ci
npm start
```

يقدّم خادم Express الواجهة المبنية من `client/dist` وواجهات الحجز من `/api` على المنفذ `3000` (أو قيمة `PORT` التي توفرها منصة الاستضافة).

## النشر

ارفع هذا المشروع إلى مستودع GitHub، ثم اربط المستودع بمنصة استضافة تدعم Node.js وشغّل أوامر بناء الواجهة وتشغيل الخادم أعلاه. **GitHub Pages لا يشغّل خادم Express**؛ لذلك لا يكفي نشر الواجهة عليه لتفعيل الحجز. كما أن الحجوزات تُحفظ في `server/data/bookings.json`، لذا اختر استضافة توفر قرصاً دائماً إذا كنت تريد الاحتفاظ بها بعد إعادة تشغيل التطبيق أو إعادة نشره.

ملف الحجوزات محلي ومستبعد من Git؛ ينشئه الخادم تلقائياً عند التشغيل.
